# loan-approval
This project is a ML based system which predicts the loan approval of a particular applicant by the bank based on the data.
This project uses multiple ML based models to compare which one works the best.
The models used to train the system are logistic regression, KNN, Naive Bayes, Decision Tree Classifier, Random Foresh and SVC.
The best model (Decision Tree Classifier) gave an Accuracy of 92% and Precision of 83.58%
